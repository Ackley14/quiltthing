Keyboard & mouse shortcuts
Global
• 1 / 2 / 3 / 4 / 5 — switch view
• Ctrl+Z — undo last change
• Ctrl+Shift+Z — redo
• Ctrl+D — duplicate selected block
• Delete — clear selected layout cell or delete selected stash block
Quilt Layout
• Click cell — place active block
• Click same block again — rotate +90°
• Shift+Click — rotate existing +90°
• Alt+Click — apply current rotation, keep block
• Right-click — clear cell
• Esc — deselect
Block Design (drawn)
• Click grid dot — add to polygon
• Click first dot — close & fill
• Click filled region — recolor
• Esc — cancel in-progress polygon
Compound Block
• Click empty slot — select it
• Click stash block — fill selected slot
